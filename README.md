# Foodpedia｜今天吃什麼？美食百科

一個以原生 HTML、CSS、JavaScript 製作的靜態美食探索網站，提供料理搜尋、國家／風格分類、餐點類型分類、預算篩選、隨機推薦與料理詳情。

## 專案特色
- 不需後端與 API Key，可直接部署 GitHub Pages。
- 料理資料集中於 `data/foods.js`，網頁自動生成卡片及篩選選項。
- `AGENTS.md` 明確規定開發、命名、資料格式與驗收流程，方便 AI 持續擴充。
- 支援桌面與手機版。

## 如何使用
開啟 `index.html` 即可操作。部署時，將全部檔案上傳到 GitHub 儲存庫根目錄，再到 Settings → Pages → Deploy from a branch → main / (root) → Save。

## 專案結構
詳見 `AGENTS.md`。

## 如何新增料理
1. 先閱讀 `AGENTS.md`。
2. 在 `data/foods.js` 的 `window.FOODS` 陣列新增符合欄位規則的料理物件。
3. 重新整理網頁，新卡片與新分類就會自動出現。
4. 測試搜尋、篩選、隨機推薦、詳情及手機版。
